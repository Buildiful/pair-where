# Active card artwork

Pair Where? displays the images in this folder. Replace `01.png`–`18.png` with PNG artwork you are authorized to publish. Square transparent PNGs around 512 × 512 pixels work well. Keep the exact filenames; no game code edits are needed.

- `01.png` appears on cards 1 and 2.
- `02.png` appears on cards 3 and 4.
- Continue in pairs through `18.png` on cards 35 and 36.
