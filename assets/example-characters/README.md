# Example character artwork

These 18 original geometric robot placeholders are supplied as reusable example artwork, separately from Buildiful®'s Beebbot characters.

- `png/01.png` through `png/18.png`: ready-to-use images.
- `svg/01.svg` through `svg/18.svg`: editable vector sources.

**License:** MIT License, as included in the repository's root `LICENSE`. You may use, modify, and redistribute these example images with the required license notice. They are not official Beebbot character artwork.

## Change the game's images

The game reads `assets/characters/01.png` through `18.png`. Copy any set of 18 PNG images into that folder, preserving the numbered filenames. Characters 01–18 correspond to cards 1–2, 3–4, …, 35–36 respectively.

For a publicly redistributed fork, replace the separately reserved Buildiful branding (logo and favicons) and do not represent the example artwork as official Beebbots. See `TRADEMARKS.md`.
